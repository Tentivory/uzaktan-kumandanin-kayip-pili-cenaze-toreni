# Uzaktan Kumandanın Kayıp Pili İçin Resmi Cenaze Töreni

> **Ulusal Oturma Odası Protokolü · Sürüm 0.0.1-yas**  
> Televizyon yas tutar. Kanepe tanıktır. Çay bardağı göz yaşı ölçer.

Bu yazılım, koltuğun altına düşmüş, yatağın kıvrımında kaybolmuş veya "bir dakika sonra bulurum" diye evrenin karanlık maddesine karışmış **uzaktan kumanda pilinin** resmi cenaze törenini yönetir.

Bilimsel olarak kanıtlanmıştır ki (kaynak: bu README), bir pil kaybolduğunda:

1. Televizyon kendiliğinden reklam kanalına geçer.
2. Aile içinde sessiz bir anayasa krizi başlar.
3. Herkes "ben buraya koymuştum" der.
4. Hiç kimse doğru söylemez.

## Kurulum

```bash
python3 cenaze.py
```

Bağımlılık yoktur. Evren yeterince bağımlıdır zaten.

## Ne yapar?

- Yas tutan eşyaları listeler.
- Resmi bir nutuk okur.
- Taziye defteri açar.
- Yeni pil alınıp alınmayacağını referanduma götürür.
- Sonuç ne olursa olsun çay önerir.
